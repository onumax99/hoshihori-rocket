# 🚀 ほしほりロケット

重力のある2D宇宙で、星を掘って資材を集め、ロケットを強化しながら星々を旅するゲーム。

## 遊び方
`index.html` をブラウザで開くだけ。

- ◀ ▶ … 向きを回す（着陸中は地面を移動）
- 🔥 … 噴射
- ⛏ … 着陸中に長押しで掘る
- ふるさと星の基地に着陸 → 荷下ろし・給油・修理・ガレージで強化
- 目標：星晶を集めて「星間エンジン」を完成させる

キーボード：←→ / A D 回転、↑ / W 噴射、Space / ↓ 掘る、E ガレージ、M マップ、T 時間加速

## 開発
開発メモは [CLAUDE.md](CLAUDE.md)。動作確認は `npm install && npx playwright install chromium && npm test`。
